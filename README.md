# Fraud Detection App

## 1. Install Requirements
Install the necessary Python dependencies before running the application:

pip install -r requriments.txt
Launch the Streamlit web app by running this exact command in your terminal:
python -m streamlit run frauddetection.py
├── analysis_model.ipynb          # Jupyter notebook with data analysis and training
├── fraud_detection_model.pkl     # Pre-trained Machine Learning pipeline
├── frauddetection.py             # Main Streamlit application script
└── requriments.txt               # Required Python packages
